# CAT-ASTROPHE!

A flying-cat arcade game with procedural Canvas artwork, synthesized audio, optional mischief targets, a beginner walkthrough, local progression, and global leaderboards.

**Play: https://catastrophe-rho.vercel.app/**

Browser gameplay is plain JavaScript. Online scores use a Vercel Function and Neon PostgreSQL. Offline play needs neither credentials nor a database. Artwork and sound are generated by code; there are no external image/audio downloads.

## Quick start

Use **Node.js 22 LTS or newer** and npm. Node 22+ satisfies the installed Neon driver; development has also been exercised on Node 26.

```powershell
git clone https://github.com/fazalhassan23/CatAstrophe.git
cd CatAstrophe
npm ci
npm start
```

Open **http://127.0.0.1:4173/**. The local server binds to this computer only, disables caching, and serves source files. It does not execute API routes. Stop it with Ctrl+C. Set `$env:PORT = '4174'` before starting to use another port.

```powershell
npm test
npm run build
```

The build embeds HTML, CSS, and browser scripts into **`dist/cat-astrophe.html`**. Open that file directly for offline play. Online features fail gracefully without an API. Edit source files, then rebuild; do not edit generated HTML directly. Tests need dependencies installed but no Neon credentials: database tests run PostgreSQL through embedded PGlite.

For API development use Vercel CLI's `vercel dev` with a separate development database; see operations. `npm start` is for browser gameplay only.

## Play

- Space / Arrow Up / tap or click the sky: flap.
- X / ability button: charged Zoomies or Air Pounce.
- P / Escape / pause button: pause/resume. Losing focus pauses automatically.
- Three taps escape yarn immediately; otherwise wait for automatic escape.
- Learn to fly provides safe, replayable practice that cannot bank rewards.

Three cats have different silhouettes and physics. Dodge six household hazards, collect fish and powers, trigger optional pot/bell/pigeon mischief, and travel through three worlds. Hearts grant extra rescues within the current flight; the game does not start with nine lives.

After a real online flight, enter a nickname to submit a score. Classic and UTC Daily boards retain/display the **top 100 flights** each. Nicknames are public and not authenticated accounts; repeated names are allowed. Unlocks, purchases, settings, and progression remain local to each browser origin/profile.

## Developer tools

Open `http://127.0.0.1:4173/?dev=1`, then Settings → Flight lab. Scenarios reproduce near misses, yarn, armor, magnet, catnip, rescue, worlds, vacuum, and mischief. Lab cannot bank progression; developer mode does not submit online scores. D toggles collision diagnostics. `?seed=123` selects a reproducible Classic seed; Daily uses its UTC date seed.

## Our cats

The characters honor Luna, Coco, and Pepe. Open **Our cats** from the menu, or **Meet [name]** in the cat collection, to see their family photos and stories. Stories are optional and gently introduce loss/missing-pet themes. Photos are in `assets/cats/`, story text in `src/stories.js`, and the build embeds them for offline reading. The gameplay artwork remains the established cartoon style. Internal IDs `biscuit`, `mochi`, and `pounce` remain stable for existing saves and score rows; only display names changed. Do not rename those IDs as a cosmetic edit. Family photos and stories should not be repurposed without the owner’s permission.
